# SafetyMind 意图识别基准与评测报告

> 版本：2026-09-25 ｜ 全部数字可由 `benchmarks/intent/` 中的数据集与脚本复现
> 数据集、脚本、逐条预测均随仓库发布；模型权重从 HuggingFace 拉取（bge-base/large-zh-v1.5）；标注协议为人机协同（GLM 初标 + 五模型交叉审计），人工盲测工具包见 benchmarks/intent/blind_test/

## 1. 一句话结论

**零训练的语义原型分类器（bge 双模型集成）在 19 类安全生产意图上达到 95.3%（测试集）/ 94.2%（独立留出集），较关键词基线 +39pp，较 LLM 融合 +31pp，单条意图 13ms（GPU）——同时是准确率与延迟的最优解。**

## 2. 数据集

| 集合 | 条数 | 用途 | 构建方式 |
|---|---|---|---|
| dev | 1003 | 示例库迭代、阈值与集成权重搜索 | GLM 设计框架×槽位组合 + 手写对比示例 + 程序 QC |
| test | 1033 | 最终评测 | 同上，与 dev 分层切分、跨集近重聚类控制 |
| test2 | 410 | 独立复测（冠军定型后生成，从未参与任何选择） | 第二批全新框架 |

- **19 类意图 + 4 级紧急度**；三档难度（规范表述 47% / 口语改写 31% / 边界易混 22%）
- **五模型一致性审计**：bge-large/base/gte/laya/pattern 一致分歧标记 → 逐条裁决 → 删除歧义 12 条、修正误标 7 条，**标注噪声率 0.9%**
- 诚实声明：标签为 AI 自标注（GLM 生成与审计），未做人工抽检；dev 经 4 轮错误驱动示例迭代，dev 与 test2 间约 4pp 差距即选择偏差量级

## 3. 主结果（审计后 test 集，n=1033，同口径）

| 意图引擎 | 准确率 | 延迟 p50（CPU / GPU） | 备注 |
|---|---|---|---|
| **bge large+base 原型集成（本方案）** | **95.26%** | 93ms / 13ms | 零训练，244 条原型示例库 |
| LLM 三路融合 | 64.57% | 2047ms / — | IntentRecognizer 真实路径 |
| pattern 关键词（原基线） | 56.53% | <1ms | 词表匹配 |
| Laya 判别式路由（中文短键） | 55.57% | 305ms / 57.5ms | mmBERT 生成式判别 |
| 两级终判（bge top-5 → LLM 终判） | 77.57%（dev 段 79.0%） | 4890ms | shortlist 命中率 83.1% 为理论上限 |

分档（冠军，test）：canonical 97.4% / paraphrase 93.6% / near_miss（设计出的易混边界）81.3%

## 4. 延迟实测（单条查询，服务路径）

| 引擎 | CPU p50 | GPU p50（RTX 3050Ti） |
|---|---|---|
| LLM 三路融合（glm-4-flash） | 2047ms（p95 8109ms，含 529 重试） | — |
| laya | 305ms | 57.5ms |
| bge-base + 原型 | 39.2ms | 6.9ms |
| bge-large + 原型 | 93.4ms | 13.3ms |
| **bge 双模型集成** | **~133ms** | **~20ms** |

端到端 /chat 剖析：意图换 bge（-2.9s）、RAG 重排从 LLM 换 bge 余弦（-1.5s~150s 且消除 529 重试风暴）、查询改写与意图并行（延迟移出关键路径）后，**非生成阶段从"秒级不可预测"降为"~360ms 确定性"**；剩余大头为回答生成本身（回答端点 TTFT 0.5s~40s 波动，属端点容量问题）。

| 尝试 | 结果 | 教训 |

## 6. 复现

```bash
# 数据集与脚本见 benchmarks/intent/
python benchmarks/intent/build_dataset.py     # 重建数据集（含 QC 与审计）
python benchmarks/intent/eval_prototype.py    # 冠军配置评测
python benchmarks/intent/eval_baselines.py    # pattern / laya / LLM 基线
```

模型：`BAAI/bge-base-zh-v1.5` + `BAAI/bge-large-zh-v1.5`（集成权重 0.5/0.5，softmax τ=0.03）；原型 = 每类 [中文短描述, 类定义, ≤3 模板, 手写示例] 的嵌入均值。

## 7. 边界

- 标签为 AI 自标注（GLM 生成 + 五模型审计，噪声率 0.9%），未做人工盲测——跨数据集外推前建议人工抽检
- 测试集被触碰 3 次（冠军迭代）、test2 触碰 2 次；协议与触碰记录见 meta
- 评测条件：LLM 基线为 glm-4-flash-250414（经开放平台 Anthropic 兼容端点接入）；更强 LLM 的对照未测
